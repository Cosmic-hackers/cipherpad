How we protect your note
Encrypted in your browser

Your note is encrypted using the Web Crypto API before it leaves your device. We never see plaintext.

Password never transmitted

Your password is used only to derive a local key. It never enters a network request — not even to us.

Password cannot be recovered

If you forget your password, the note cannot be decrypted — not by us, not by anyone. Store it safely.
