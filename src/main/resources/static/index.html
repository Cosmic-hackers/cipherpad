Security model

Zero-knowledge design

Your password is derived into an encryption key inside your browser. Only ciphertext touches our servers.

Client-side only encryption

Web Crypto API runs entirely in your browser. The raw key never exists on our infrastructure.

Separate access token

A random 256-bit access token gates API access. We store only its SHA-256 hash — never the token itself.

Fresh IV every save

AES-GCM uses a new random 12-byte nonce on each encryption — IVs are never reused with the same key.
